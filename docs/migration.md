# Baseline provenance

The clean baseline selectively reuses original catalog, display and Godot library code, with a separately extracted libretro boundary. The source-path allowlist records the initial files copied; subsequent work is ordinary versioned development. No previous Git history is imported.

Previous cartridge-review changes are handled by the independent model collection rather than copied into this application. External-process launch work does not define the embedded-emulation path. Earlier controller navigation, settings, visual-system, async-work and platform tasks were consolidated into the current milestone and future items in plan.md. Private deployment/runner tasks are not public application work.

Historical repositories retain their original issues, branches and pull requests privately. No private issue bodies or operational evidence were transferred. Archive additions require a reason to retain inactive code; an empty archive is preferable to a duplicate active implementation.
