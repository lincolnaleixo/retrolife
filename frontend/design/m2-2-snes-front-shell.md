# M2.2 provisional NTSC-U SNES front shell v2

`retrolife.snes.na-cartridge.m2.2.front.v1` is rejected as plate-stacked production geometry. `retrolife.snes.na-cartridge.m2.2.front.v2` is a clean continuous-surface rebuild from the public M2.1 contract; it does not import or adapt v1.

The shell is one connected watertight surface. Label recess, lower grip channel, five wing grooves and screw wells are depth changes in that surface. Godot regenerates the mesh deterministically at scene load rather than committing a multi-megabyte intermediate OBJ.

Physical calibration and explicit owner visual approval remain required. M2.3 and M3 stay blocked.
