# RetroLife icon

## Boot splash

`retrolife-splash.svg` is original RetroLife interface artwork drawn as vector paths on 2026-10-23. It contains a cartridge with a pixel heart and an original outlined wordmark, with no game artwork or manufacturer marks. `retrolife-splash.png` is its matching raster version because Godot's early boot splash accepts PNG only. It can be reproduced with Godot's `Image.load_from_file(svg_path).save_png(png_path)`. Both are licensed with the original application code. The splash uses the application's dark background and introduces no loading-progress claims.

Original RetroLife app branding generated with the built-in image generator on 2026-10-22. No console manufacturer marks or game artwork are included. The PNG is used by the app header, Godot project and macOS export preset.

## Generation prompt

Use case: logo-brand. Create the finished macOS app icon for RetroLife, a premium personal retro videogame collection and play app. One single square icon, no text or letters. A sculpted warm ivory vintage cartridge with a small vivid mint pixel heart inset into a deep midnight indigo label, subtle lavender side bevel, elegant tactile satin materials, beautifully controlled studio highlights. Rounded square midnight indigo tile with generous corner rounding, cartridge centered and slightly isometric but simple readable silhouette at 32px. Nostalgic yet sophisticated, collectible object, playful warm personality, clean surfaces, pristine. No existing console manufacturer logos, no Nintendo/Sega/Sony marks, no controller buttons, no busy scenery, no watermark. Tile fills almost all the 1024x1024 canvas with transparent outer corners, excellent icon legibility.
